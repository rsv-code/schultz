33 * Everything declared below is part of the host facing interface, so it is
34 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
35 * hides everything by default: that is what stops a shared library built
36 * from it exporting the whole of FreeType, libpng and zlib alongside, where
37 * they would meet the copies already loaded by whatever is hosting it.
38 *
39 * A pragma rather than an attribute on each declaration, because there are
40 * some hundreds of them and one pair of lines per header says the same thing.
