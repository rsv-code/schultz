54/*
55 * Everything declared below is part of the host facing interface, so it is
56 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
57 * hides everything by default: that is what stops a shared library built
58 * from it exporting the whole of FreeType, libpng and zlib alongside, where
59 * they would meet the copies already loaded by whatever is hosting it.
60 *
61 * A pragma rather than an attribute on each declaration, because there are
62 * some hundreds of them and one pair of lines per header says the same thing.
63 */
