34/*
35 * Everything declared below is part of the host facing interface, so it is
36 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
37 * hides everything by default: that is what stops a shared library built
38 * from it exporting the whole of FreeType, libpng and zlib alongside, where
39 * they would meet the copies already loaded by whatever is hosting it.
40 *
41 * A pragma rather than an attribute on each declaration, because there are
42 * some hundreds of them and one pair of lines per header says the same thing.
