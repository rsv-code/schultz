38/*
39 * Everything declared below is part of the host facing interface, so it is
40 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
41 * hides everything by default: that is what stops a shared library built
42 * from it exporting the whole of FreeType, libpng and zlib alongside, where
43 * they would meet the copies already loaded by whatever is hosting it.
44 *
45 * A pragma rather than an attribute on each declaration, because there are
46 * some hundreds of them and one pair of lines per header says the same thing.
47 */
