113 /*
114 * The shape scale is split by how close a thing is to the finger, not by
115 * how big it is. When every surface shares one radius, a button and the
116 * card behind it read as the same kind of object and the thing meant to
117 * be pressed stops standing out. So structure is square and the objects
118 * you press are round, and the contrast between them is what says which
119 * is which.

121 * Depth is carried by surface tone, so the radius does not have to carry
