Detailed Description

What a render needs besides the tree itself.

The tree knows its own fonts and images, but a render also needs the glyph cache and the gradient table, which live beside the renderer rather than in the tree. Zero initialize this and fill in what applies: a tree with no text needs no fonts, and one with no gradients needs no resources.
