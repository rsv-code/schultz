void* schultz_a11y_options::native_window

The platform's own window, as SDL_Window *, or NULL.

Accessibility on Windows, macOS, iOS and Android attaches to a native window or view rather than announcing itself the way Linux does, and this is the only way to reach one from here. Linux ignores it.
