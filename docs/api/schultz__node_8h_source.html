46/*
47 * Everything declared below is part of the host facing interface, so it is
48 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
49 * hides everything by default: that is what stops a shared library built
50 * from it exporting the whole of FreeType, libpng and zlib alongside, where
51 * they would meet the copies already loaded by whatever is hosting it.
52 *
53 * A pragma rather than an attribute on each declaration, because there are
54 * some hundreds of them and one pair of lines per header says the same thing.
55 */
