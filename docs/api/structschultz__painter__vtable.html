Detailed Description

The painter interface a rendering backend implements.

Every entry must be non-NULL. schultz_draw_list_play rejects an incomplete vtable rather than silently skipping drawing, because a missing entry would otherwise show up as content that never appears.

Each command handler receives the whole command; read the union member that matches its kind. Handlers return SCHULTZ_OK to continue, or any error to abort the frame.
