Detailed Description

Minimum, preferred and maximum size along both axes.

A preferred size of a negative value means "ask the pane", which is the usual case: a container derives its preferred size from its children. A maximum of a negative value means no maximum.

Preferred is a wish; minimum and maximum are rules. A preferred size says how big a node would like to be when nothing else decides, and a pane is entitled to decide otherwise: a box pane stretches its children across the cross axis by default. A minimum and a maximum bind wherever a node is placed, not only where it is measured.
