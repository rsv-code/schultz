Detailed Description

One line produced by wrapping.

Offsets are byte offsets into the original string, so a caller can shape or highlight the line without copying it.

float schultz_text_line::height

Line height of the tallest face on this line. Measuring already had to shape the line to learn its width, so this costs nothing and saves a caller shaping it again only to find out how tall it is. With one face throughout it is that face's line height, every line the same.
