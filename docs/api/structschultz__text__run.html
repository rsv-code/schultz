Detailed Description

One shaped run: glyphs ready to draw, plus its extent.

The glyphs are allocated from the arena passed to the shaping call, so they live until that arena is reset. Positions are relative to the run's origin, which sits on the baseline at the leading edge.

◆ clusters

const uint32_t* schultz_text_run::clusters

Byte offset into the source string each glyph came from, one per glyph. Several glyphs may share one offset when a character shapes into more than one, and one glyph may cover several bytes when characters combine. This is what a caret is placed from.

◆ fonts

const schultz_handle* schultz_text_run::fonts

The face each glyph came from, one per glyph. Usually every entry is the font that was asked for; it differs where the string held something that face could not draw and the emoji face supplied it. A painter draws consecutive glyphs sharing a face as one run.
