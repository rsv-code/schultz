35/*
36 * Everything declared below is part of the host facing interface, so it is
37 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
38 * hides everything by default: that is what stops a shared library built
39 * from it exporting the whole of FreeType, libpng and zlib alongside, where
40 * they would meet the copies already loaded by whatever is hosting it.
41 *
42 * A pragma rather than an attribute on each declaration, because there are
43 * some hundreds of them and one pair of lines per header says the same thing.
