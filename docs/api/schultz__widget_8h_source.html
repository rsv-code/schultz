39/*
40 * Everything declared below is part of the host facing interface, so it is
41 * marked visible. The toolkit is compiled with -fvisibility=hidden, which
42 * hides everything by default: that is what stops a shared library built
43 * from it exporting the whole of FreeType, libpng and zlib alongside, where
44 * they would meet the copies already loaded by whatever is hosting it.
45 *
46 * A pragma rather than an attribute on each declaration, because there are
47 * some hundreds of them and one pair of lines per header says the same thing.
48 */
